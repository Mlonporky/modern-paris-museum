# Modern Paris Online Museum Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a Chinese, single-page Astro 6 online exhibition that explains Impressionism through nineteenth-century Parisian art, history, society, and economics.

**Architecture:** Astro generates a static site from two build-time Content Collections: Markdown artwork entries loaded with `glob()` and JSON timeline entries loaded with `file()`. Focused Astro components render the magazine-style page, one small browser module powers the quiz, Node's built-in test runner checks generated HTML and quiz logic, and GitHub Actions publishes the build to GitHub Pages.

**Tech Stack:** Astro 6, TypeScript content schemas, Markdown, JSON, native HTML/CSS/JavaScript, Node 24 test runner, npm, GitHub Actions, GitHub Pages.

**Learning workflow:** Before each task, explain the concept in plain Chinese. After each small edit, show the inline diff, preview the visible result, explain the relevant HTML/CSS/JavaScript, and ask for confirmation before continuing. Because this Codex sandbox can read but not write `.git`, Codex prepares and verifies files; the user runs the listed `git add` and `git commit` commands in PowerShell at each checkpoint.

- [ ] **Step 1: Define the artwork collection schema**

Create `src/content.config.ts`:

```ts
import { defineCollection } from 'astro:content';
import { glob } from 'astro/loaders';
import { z } from 'astro/zod';

const artworks = defineCollection({
  loader: glob({ pattern: '**/*.md', base: './src/data/artworks' }),
  schema: z.object({
    title: z.string().min(1),
    originalTitle: z.string().min(1).optional(),
    artist: z.string().min(1),
    artistOriginal: z.string().min(1),
    year: z.number().int().min(1800).max(1900),
    theme: z.string().min(1),
    order: z.number().int().positive(),
    image: z.string().min(1),
    imageAlt: z.string().min(20),
    museum: z.string().min(1),
    sourceUrl: z.url(),
    imageSourceUrl: z.url(),
    rightsNote: z.string().min(1),
    timelineIds: z.array(z.string().min(1)).min(1),
  }),
});

export const collections = { artworks };
```

## 看见什么

画面像一次突然停住的街头观察。路灯把构图切开，近处人物被画框截断，远处行人缩进宽阔街道。清晰的建筑透视与松散的人群形成张力：城市秩序井然，人与人却很少交流。

## 时代发生了什么

卡耶博特描绘的是奥斯曼改造后出现的新巴黎。旧街区被宽阔林荫大道、统一立面、排水设施和交通网络重新组织。新街道改善了通行和卫生，也带来拆迁、租金变化及更强的社会分区。

## 钱与生活如何改变

铺路、地产开发和商业门面共同改变了城市价值。衣着体面的行人成为新大道的典型使用者，而维持城市运转的劳动常被排除在画面中心之外。作品因此既展示现代化，也让人追问谁能够自在地享受现代城市。

export function evaluateAnswer(selected, correct, explanation) {
  if (!selected) {
    return { status: 'unanswered', message: '请先选择一个答案。' };
  }

  if (selected === correct) {
    return { status: 'correct', message: `回答正确。${explanation}` };
  }

  return { status: 'incorrect', message: `还差一点。${explanation}` };
}
